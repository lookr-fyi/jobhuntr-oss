# Changelog

## 1.0.0

First stable public local-first release.

- Complete job-search command center, application tracker, offline board, submission queue, Resume Studio, interview coach, profile audit, autonomous hunt, outreach, and gigs pipeline.
- One-line clean-checkout launch with no account, API key, hosted database, object storage, telemetry, or cloud dependency.
- Atomic serialized JSON persistence, schema migration, backup recovery, JSON/CSV portability, localhost-only networking, and restrictive browser headers.
- AGPL-3.0 licensing, contributor safeguards, formatting/lint gates, production build verification, architectural dependency guard, and complete-Git-history secret scanning.

Earlier `0.x` releases incrementally established the local-first foundation and each product parity surface. See the Git history for per-release commits.
